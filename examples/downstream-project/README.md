# Downstream Project Example

This example shows how to use the sensenet flake module in your own project.

## Quick Start

```bash
# Enter the development shell (sets up Buck2 + toolchains)
nix develop

# Build the example binary
buck2 build //src:hello

# Run it
buck2 run //src:hello
```

## What the Flake Module Provides

When you `nix develop`, the sensenet flake module:

1. **Generates `.buckconfig.local`** with Nix store paths for all toolchains
2. **Symlinks `nix/build/prelude`** to the Buck2 prelude
3. **Copies `nix/build/toolchains`** with sensenet toolchain rules
4. **Adds `buck2` to PATH**

## Project Structure

```
.
├── flake.nix           # Imports sensenet.flakeModules.sensenet
├── .buckconfig         # Minimum required Buck2 config
├── src/
│   ├── BUCK            # Buck2 build file
│   └── main.cpp        # Source code
└── nix/build/          # Generated by nix develop
    ├── prelude/        # Symlink to Buck2 prelude
    └── toolchains/     # Sensenet toolchain rules
```

## Configuration Options

### Toolchains

Enable the toolchains you need in `flake.nix`:

```nix
sensenet.projects.example = {
  toolchain = {
    cxx.enable = true;      # LLVM/Clang (C/C++)
    rust.enable = true;     # Rust (rustc + cargo)
    haskell.enable = true;  # GHC with packages
    python.enable = true;   # Python with nanobind/pybind11
  };
};
```

### Remote Execution

To use NativeLink for remote builds:

```nix
sensenet.projects.example = {
  toolchain.cxx.enable = true;
  
  remoteexecution = {
    enable = true;
    scheduler = "scheduler.example.com";
    cas = "cas.example.com";
    schedulerPort = 443;
    casPort = 443;
    # authtoken = "your-token";  # For authenticated endpoints
  };
};
```

Then build with `--prefer-remote`:

```bash
buck2 build --prefer-remote //src:hello
```

## .buckconfig Explained

The minimum `.buckconfig` you need:

```ini
[cells]
root = .
prelude = nix/build/prelude      # Generated symlink
toolchains = nix/build/toolchains # Generated copy

[parser]
target_platform_detector_spec = target:root//...->prelude//platforms:default

[build]
execution_platforms = toolchains//:local
```

The flake module generates `.buckconfig.local` with:
- Toolchain paths (`[cxx]`, `[rust]`, etc.)
- Remote execution settings (`[buck2_re_client]`)
